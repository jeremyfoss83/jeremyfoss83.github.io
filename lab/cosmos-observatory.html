01 / Orientation

A system in perspective.

Begin at the ecliptic plane, then travel outward to see how distance, inclination, and time shape the architecture of the solar system.

Observatory loading. The default visualization uses JPL barycentric samples beginning 2026-01-01 TDB in the ICRF ecliptic frame. Use the body catalog or left and right bracket keys to select an object, the timeline to change date, and Space while the canvas is focused to play or pause.

Why build an observatory?

Wonder becomes more powerful when the model stays honest.

I am drawn to space because it lets us explore the unknown, discover new truths about the universe, and ask what our existence within it means.

This instrument turns that curiosity into an inspectable system: a visual experience backed by documented inputs, visible assumptions, and a direct comparison between reference data and a deliberately simpler browser model.

Methodology / Provenance

What the instrument shows—and what it does not.

COSMOS Observatory is an educational visualization and front-end engineering project. It is not an operational ephemeris, navigation system, aerospace analysis package, or substitute for JPL tools.

01

JPL reference states

The local dataset records selected barycentric planetary states tied to a documented time scale and frame. The renderer linearly interpolates between immutable 10-day samples for visual continuity; those between-sample states are not fresh Horizons results or a live feed.

Horizons system manual ↗
02

Local propagation & comparison

The browser independently advances a simplified two-body/Keplerian model. Compare mode plots the local result beside its reference state and reports a residual. Divergence is expected: the local model omits many-body perturbations and other terms present in high-precision ephemerides.

JPL approximate positions & formulae ↗
03

Scale compromises

No single screen can show planetary radii and interplanetary distances at the same legible physical scale. Both modes preserve relative orbital spacing. The default exaggerates body radii; “Relative body radii” uses the physical radius-to-distance relationship with a small selectable-symbol floor.

Mean anomalyM(t) = M₀ + n(t − t₀)
04

Three-dimensional rendering

State vectors are transformed into camera space, projected with depth, and rendered with orbit planes, restrained atmospheric cues, and a chunked procedural starfield. Visual lighting communicates form; it does not simulate radiometry.

State residualΔr = ‖rmodel − rref‖
05

Interaction & accessibility

Every persistent layer has an HTML control. The canvas is keyboard-focusable, major state changes update a live DOM summary, color is reinforced with shape and text, and reduced-motion settings suppress cinematic transitions. The guided tour can be exited at any time.

06

Reproducibility & limits

Reference values ship with the site so the visualization does not depend on network availability. Values are rounded for display. Epoch, reference frame, scale mode, and source remain visible so a compelling scene never obscures the model’s boundaries.
