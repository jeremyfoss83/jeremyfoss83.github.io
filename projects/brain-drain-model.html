Simulation · Case Study 01

Brain Drain Agent-Based Model

An experimental model for examining how migration costs, subsidies, policy barriers, and skill differences can influence movement between regions.

CourseAgent-Based Modeling
TermSpring 2026
ToolsNetLogo · Python · Excel
OutcomeCourse grade: A

The question

Brain drain is shaped by more than a single economic incentive. The project asked how individual skill tiers and policy variables might interact to influence migration patterns within a simplified simulated environment.

My approach

I built and modified NetLogo models that represented agents with different skill characteristics. Policy controls introduced migration costs, subsidies, and barriers, allowing scenarios to be compared without presenting the model as a prediction of real-world behavior.

  • Defined agent differences and adjustable policy parameters.
  • Designed repeated BehaviorSpace experiments.
  • Exported results to CSV for comparison and summary.
  • Calculated means and standard deviations across runs.
  • Conducted parameter and sensitivity testing.

What the work demonstrated

The strongest part of the project was the experimental process: turn assumptions into explicit model rules, isolate parameters, repeat runs, and document uncertainty. I also delivered a seven-minute lightning talk explaining the model and results.

Evidence boundary: This was an academic simulation. Its outputs help compare modeled scenarios; they do not establish causal claims about real migration systems.

What I would improve next

I would add stronger calibration data, formalize the experiment matrix before implementation, and build reproducible analysis scripts that generate charts directly from BehaviorSpace outputs.
